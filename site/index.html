This is what Atmos looks like:

Try Atmos online → 
;; During five seconds,
;; prints "Hello World!" every second.
watching 5s {
    loop on 1s {
        print "Hello World!"
    }
}

Features

  • Structured: each line of execution belongs to a block; when the block ends, everything inside it is aborted and finalized.
  • Reactive: waiting is a statement; a program awaits events in sequence, with no callbacks.
  • Concurrency: lines of execution run side by side, with deterministic, synchronous scheduling.
