Structured Event-Driven Concurrency

Programming languages for reactive systems: games, interfaces, embedded devices.

A reactive program spends its life waiting: for a key, a click, a timer, a message. In these languages, waiting is a statement. A program awaits events in sequence, as plain structured code, and runs lines of execution side by side with deterministic scheduling. A line of execution lives inside a block: when the block ends, everything inside it is aborted and finalized, with no callbacks and no manual cleanup.

Features

  • Structured event handling: await an event, as any other statement
  • Synchronous and discrete execution, with deterministic scheduling
  • Concurrency with lexical scope: abortion and finalization are safe
  • Small memory footprint, no tracing garbage collector
  • Seamless integration with C
