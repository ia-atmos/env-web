The Programming Language Atmos

Structured Reactive Concurrency

Atmos reconciles structured concurrency and event-driven programming. A program is made of tasks that await events and run side by side, with deterministic scheduling, and that live in the lexical scope of the block that holds them. Atmos is inspired by synchronous languages such as Céu and Esterel.

Features

  • task: a line of execution with deterministic scheduling and safe abortion
  • await and emit: tasks wait for events and signal them
  • par, watching, every: structured compositions of tasks
  • tasks and pin: pools of tasks attached to a lexical scope
  • Compiles to C: no virtual machine, no interpreter, no tracing garbage collector, a small memory footprint
  • Seamless integration with C: C code inside the program, in native blocks
  • Runs on the desktop (SDL, raylib, pico-sdl) and in the browser (WebAssembly)
