# The DOM (2026-11-25)

## The old plans

`atmos-lang/web` `.claude/plans/dom.md` (Mar/2026): a 3-pane email reader
(Freechains: folders, a tree of threads, the message), with Lua over
Wasmoon as "the backend in the browser" and JS as presentation only.
- The tree is native `<details>`/`<summary>`: the attribute `open` and
  the event `toggle`, with no library (Shoelace or a custom element
  rejected: they make the DOM the data model).
- Lua calls the DOM API directly (`doc:createElement`, `addEventListener`,
  `setInterval`), almost line by line as vanilla JS; no jQuery.
- A demo page (`threads/html/index.html`) adds threads every 1 s and
  replies every 200 ms from Lua timers.
- Tasks: layout in CSS Grid, the tree, selection, folders, the message.
  None done.

`lua-atmos/env-js`: runs a program passed in the URL (base64 in the
fragment) with Wasmoon; the host emits `clock` from `setInterval`, and
the environment is `atmos.env` with `open`/`close`. `atmos-lang/web`
wraps it in an editor with a "Run" button (an iframe).

## Prototype (branch `proto-dom`, `proto/dom/`)

An environment of the browser with no change to `ia-atmos/lang`:
- `web.atm` registers a primary with no `step`; the generic `main`
  (`rt/main.c`) returns after the main chunk, and the runtime of
  Emscripten stays alive.
- The page calls `web_time(ms)` from `requestAnimationFrame` (the clock)
  and `web_event(tag, id)` from `addEventListener` (`:click [id=...]`).
- `web.text(id, s)` and `web.on(id, tag)` call JS through `EM_JS`.
- `counter.atm`: a button that counts, a clock of seconds (`await 1s`),
  a button that ends the program (`await :click until it.id == "stop"`).

Measured in Chromium headless (`test.js`):

| Step | Result |
|---|---|
| load | `msg` = "running" |
| 3 clicks on "+1" | `count` = 3 |
| 3.1 s | `secs` = 3 |
| click on "stop", then "+1" | `msg` = "stopped", `count` stays 3, the page stops calling (status 1), `print` reaches the page |
| size | `counter.wasm` 226 KB, `counter.js` 61 KB |

## Open (for the design, after `#2`)

- Elements as values (a handle of `a_nat`) instead of ids; creating
  elements (the tree of the old plan) from Atmos.
- The clock: `requestAnimationFrame` stops in a hidden tab; a timer of
  `atm_next()` with `setTimeout` instead.
- `atm_quit` is never called when the program ends (the page lives on).
- A call into JS in general (`web.js(code)`?) vs a fixed API.
