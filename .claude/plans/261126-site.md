# The guides as steps on the web, and the site (2026-11-26)

## The request

**Autor** (2026-11-26, in `env-web`):
> O objetivo no longo prazo é fazer os guias do atmos e do pico como
> passos na web, veja como ceu-lang faz.
> Na verdade, iremos substituir céu em algum momento. Inicialmente como
> diretório atmos/ , depois jogaremos a página principal para ceu/ . A
> landing page vai apontar para os dois, favorecendo Atmos.

## How ceu-lang.org does it (fetched on 2026-11-26)

- Landing (`index.html`): a tagline, a button "Try the Online
  Tutorial!" to `try.php`, a sample of code, and the sections Features,
  Learn (online tutorial, manuals, tutorials, papers) and Downloads.
  No mention of Atmos.
- `try.php`, "Try & Learn Céu" (v0.30): a side panel "Tutorial" with 16
  numbered steps (Welcome, Hello World!, Input Events, Parallel
  Compositions (5 steps), Execution Model (3), Internal Events (2),
  Asynchronous Execution (2), Simulation). One step is a title, a text,
  a code area with the buttons Code, Reset and Run, an Input box, and a
  Results area. The steps are switched in the page (their links are
  `#`). Where the code runs was not visible in what was fetched (the
  scripts were not read): to check.
- `atmos/try/` exists on the site: links to the old runners of
  `atmos-lang/web` (v0.6 and main; Atmos over Lua).

## What exists to become steps

- pico: `env-pico/doc/guide.md` (7 sections: initialization, drawing,
  positioning, views, events, layers) and `exs/birds/` (a tutorial in 11
  steps, `birds-01.atm` to `birds-11.atm`).
- Atmos: only `lang/doc/manual.md` (a reference). A guide in steps does
  not exist: to be written (the steps of Céu are a model: hello, events,
  parallel compositions, the execution model, internal events).
- The IDE (`ide/`): the editor, the two modes, Run through a server.

## The point to decide first

A step with Run needs the program compiled. The old site is deployed as
static files (`atmos-lang/web`: rsync to the host). So:
- steps built ahead: each step ships with its page already compiled;
  Run shows it; static; editing a step does nothing without a compiler;
- a compile server on the host: needs emcc there;
- compiling in the page (clang in WebAssembly): not tried.

## The site, as the author described it

1. `atmos/` beside the current site of Céu.
2. Later the current main page moves to `ceu/`.
3. A landing page that points to both, favoring Atmos.
